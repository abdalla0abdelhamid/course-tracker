# 📚 متتبع تقدم الكورس

صراحة كنت كسلان جدًا في متابعة تقدمي في كورس كنت باذاكره، وكل أدوات التراك المعروفة (Notion, Trello, إلخ) حسيت إنها معقدة أكتر من اللازم بالنسبالي - features كتير ومش محتاجها، وواجهة بتاخد وقت تتعلم تستخدمها.

فقلت أعمل حاجة بسيطة جدًا لنفسي: موديول، وتحته توبيكات، وتشيك بوكس. خلاص. مفيش أكتر من كده.

## ليه عملتها؟
- مش بحب الأدوات المعقدة أو الـ "advanced" اللي فيها features زيادة عن الحاجة.
- عايز حاجة تفتحها، تضيف اللي بتذاكره، وتأشّر عليه وانت ماشي - من غير تفكير.
- عايزها تبقى بتاعتي أنا، مش تعتمد على حساب أو سيرفر خارجي.

## المميزات
- إضافة موديولات، وتحت كل واحد توبيكات/فيديوهات.
- نسبة تقدم (%) منفصلة لكل موديول لوحده.
- طي/فرد الموديول اللي خلصته عشان الشاشة تفضل مرتبة.
- خانة "أولويات المهام" للمهام اليومية.
- خانة "أفكار طارئة" لأي فكرة تيجي في بالك تسجلها بسرعة قبل ما تنسى.
- الداتا بتتخزن محليًا (ملف JSON)، مفيش فقدان للبيانات بين التشغيلات.

## الأدوات المستخدمة
- **الباك إند:** C# (ASP.NET Core Minimal API) - بيخزن الداتا في ملف JSON محلي.
- **الفرونت إند:** React + Vite.
- تصميم بسيط بـ CSS عادي، من غير أي مكتبات UI تقيلة.
