# متتبع تقدم الكورس

باك إند C# (ASP.NET Core) + فرونت إند React (Vite). الداتا بتتخزن في ملف `data.json` جنب الباك إند، فمش بتضيع بين التشغيلات.

## التشغيل

### 1) الباك إند
```
cd backend/CourseTracker.Api
dotnet run
```
هيشتغل على `http://localhost:5000`

### 2) الفرونت إند
```
cd frontend
npm install
npm run dev
```
هيفتح على `http://localhost:5173`

افتح المتصفح على لينك الفرونت إند وابدأ ضيف الموديولات والتوبيكس.
